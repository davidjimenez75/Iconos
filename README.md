## Contenido

- **Formato:** PNG con transparencia.
- **Tamaño:** 512 × 512 px por defecto. Los ficheros con sufijo `.256.png` (p. ej. `star.256.png`) son variantes de 256 × 256 px.
- **Nomenclatura:** nombres cortos en inglés, en minúsculas y separados por guiones (`floppy-disk.png`, `card-index-dividers.png`).

## Uso

En Markdown:

```markdown
![Aviso](warning.png)
```

En HTML, con tamaño ajustado:

```html
<img src="warning.png" alt="Aviso" width="32" height="32">
```

Directamente desde GitHub:

```
https://raw.githubusercontent.com/davidjimenez75/Iconos/main/warning.png
```
